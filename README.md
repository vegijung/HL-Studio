# HL Studio

Website von HL Studio, Agentur für Websites, Automationen und Backoffice im Oberwallis.

Statisches HTML, kein Build-Schritt.

- `index.html` – Startseite
- `impressum.html` – Impressum und Datenschutz
- `styles.css` – Design

## Lokal ansehen

`index.html` im Browser öffnen.

## Veröffentlichen

Ordner bei Netlify, Vercel oder per FTP bei Infomaniak hochladen.

## Vor dem Livegang ersetzen

- Calendly-Link (`https://calendly.com/DEIN-LINK`)
- Namen, Fotos und Kurztexte im Team
- E-Mail, Telefon, Adresse (Kontakt und Impressum)
- UID im Impressum nach der Gründung
- Preise prüfen
